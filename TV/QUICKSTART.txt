📦 ШАГ 1: УСТАНОВКА yt-dlp
──────────────────────────────────────────────────────────────
    pip install yt-dlp

    Проверка:
    yt-dlp --version


⚙️ ШАГ 2: НАСТРОЙКА download.php
──────────────────────────────────────────────────────────────
    Откройте download.php, найдите строку 9-11:

    Windows:
        $YT_DLP_PATH = 'yt-dlp';

    Linux/Mac:
        $YT_DLP_PATH = '/usr/local/bin/yt-dlp';

    Узнать путь:
        Windows: where yt-dlp
        Linux/Mac: which yt-dlp


🚀 ШАГ 3: ЗАПУСК
──────────────────────────────────────────────────────────────
    Способ 1 - PHP сервер (простой):
        cd TV
        php -S localhost:8000
        
        Открыть: http://localhost:8000/index.html

    Способ 2 - XAMPP/OpenServer:
        Скопировать папку TV в htdocs/domains
        Открыть: http://localhost/TV/index.html


✅ ШАГ 4: ИСПОЛЬЗОВАНИЕ
──────────────────────────────────────────────────────────────
    1. Откройте index.html в браузере
    2. Вставьте ссылку на YouTube/Rutube/VK видео
    3. Выберите качество (best/1080p/720p/480p/360p)
    4. Нажмите "Скачать видео"
    5. Файл загрузится в папку downloads/

   🐛 ЧАСТЫЕ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════

    ❌ "yt-dlp not found"
       → pip install yt-dlp
       → Проверьте путь в download.php

    ❌ "Permission denied" (Linux)
       → chmod 755 download.php
       → chmod 755 downloads/

    ❌ Ошибка 403/429
       → pip install -U yt-dlp
       → Подождите 5-10 минут

    ❌ Яндекс.Видео не работает
       → Найдите оригинальный источник (YouTube/Rutube)
       → Используйте ссылку с оригинала
